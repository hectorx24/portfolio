## ✦ Overview

This repository powers the live personal portfolio at **[https://hector-portfolio-sigma.vercel.app](https://hector-portfolio-sigma.vercel.app)**. It showcases real, compiled, and hardware-tested systems across AI cognitive introspection, CRT terminal game loops, executive dysfunction support, and 10-foot television ergonomics.

### Featured Projects & Case Studies
1. **[Aura](https://github.com/hectorx24/portfolio)** — Local AI dream & subconscious analysis engine with strict privacy boundaries, Floyd-Steinberg dithered visuals, and archetype clustering.
2. **[Deep RPG Terminal](https://github.com/hectorx24/portfolio)** — 1980s retro dungeon crawler with CRT bloom shaders, live D20 game loop, and Gemini 2.5 Flash procedural dungeon master.
3. **[DualMind](https://github.com/hectorx24/portfolio)** — Cognitive prosthetic for ADHD and task paralysis featuring automatic recursive microstep decomposition and a hard limit of 3 active priorities.
4. **[Creator TV](https://github.com/hectorx24/creator-tv)** — 10-foot Patreon client engineered for Google TV / Chromecast with native Android TV IME integration, overscan compensation, and DPAD focus traversal.

### Interactive Digital Lab
The portfolio features live, in-browser runtime prototypes:
- **D20 Terminal Engine:** Real-time animated D20 dice roller with dynamic HP/XP/Gold tracking and retro ASCII scene generation.
- **Web Audio API Procedural Synthesis:** Real-time Brownian 6dB/oct lowpass noise, 8Hz Alpha binaural stereo beat generator, and Kellet pink noise with an active HTML5 Canvas oscilloscope.
- **Cognitive Microstep Simulator:** Live task decomposer that breaks down complex developer tasks into friction-reduced atomic actions.

## ✦ Tech Stack

- **Framework:** React 19 + TypeScript + Vite 8
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`)
- **Audio DSP:** Native Browser Web Audio API (`AudioContext`, `BiquadFilterNode`, `StereoPannerNode`, `AnalyserNode`)
- **Icons & Graphics:** Lucide Icons, bespoke SVG Floyd-Steinberg dithered art, custom typography
- **Deployment:** Vercel (Independent project configuration)

## ✦ Development

```bash
# Clone repository
git clone https://github.com/hectorx24/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev

# Type check & production build
npm run build
```
